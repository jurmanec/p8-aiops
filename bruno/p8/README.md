# P8 Bruno collection

Open this folder in Bruno and select the `local` environment.

`{{baseUrl}}` is `http://127.0.0.1:8787`. `{{alertKey}}` is the critical ROOM-01 series. Posting the critical firing or resolve again returns `200` when that `event_id` is already stored.

`List events` is the log. `List events for an alert` keeps the rows whose body `alert_key` matches.
