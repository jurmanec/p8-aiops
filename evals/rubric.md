# Window summary rubric

Score each dimension 1–5 against the **brief + paragraph** only. Do not reward facts that are not in the brief.

| Dimension | Look for |
| --- | --- |
| Faithfulness | No invented people, causes, times, or episodes. Free-text replies are used only as written. |
| Coverage | Still-firing condition, open ownership, discrepancies, and escalations are named when present in the brief. |
| Audience | Useful to the next on-call and to leads; lead with what is still open or firing. |
| Reply use | Weaves `Reply from …` lines into the narrative instead of only restating the stats table. |
| Conciseness | One short paragraph; no filler that repeats the table without adding judgment. |
